# Corretor Social

SaaS brasileiro de marketing automatizado para corretores de imóveis.

## Proposta central

**Cole o link do imóvel. A plataforma cria, adapta, agenda e publica a campanha nas suas redes.**

## Público inicial

Corretores autônomos brasileiros, inclusive usuários com pouca familiaridade com tecnologia.

## Princípios de produto

- simplicidade extrema;
- fluxo guiado;
- linguagem em português do Brasil;
- fotos reais do imóvel como fonte principal;
- IA de texto no fluxo principal;
- renderização programática dos criativos;
- virtual staging como recurso Premium;
- publicação orgânica primeiro;
- tráfego pago somente em fase posterior;
- sem CRM imobiliário no MVP.

## MVP

- onboarding do corretor;
- perfil profissional, CRECI, WhatsApp e identidade visual;
- conexão de Instagram/Facebook, TikTok e Google Business Profile;
- imóvel por URL, upload ou cadastro manual;
- extração e revisão dos dados;
- análise dos argumentos de venda e das melhores fotos;
- Feed, Carrossel, Story e Reel/slideshow;
- textos adaptados por rede;
- preview;
- publicar agora / agendar / publicar em todas;
- histórico de imóveis e campanhas;
- links rastreáveis para WhatsApp;
- métricas simples;
- interface Premium de virtual staging.

## Direção visual

- fundo: `#F7F8FA`
- cards: branco
- texto: `#18202A`
- secundário: `#667085`
- primária: `#176B5B`
- fonte: Inter
- visual claro, profissional, amigável e sem estética “IA futurista”.

## Desenvolvimento

O GitHub é a fonte de verdade do projeto.

Framework oficial: **Next.js App Router + TypeScript + Tailwind CSS + shadcn/ui**. O Lovable pode ser usado como apoio visual, mas o GitHub é a fonte de verdade e o código não depende do runtime do Lovable.

Backend, banco, autenticação real e integrações externas serão adicionados depois da validação visual/UX do frontend.
